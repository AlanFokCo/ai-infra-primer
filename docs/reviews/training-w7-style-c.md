## S2 明细（含糊程度词无数值，rubric B1）

### S2-1 · 7.2 §6（02-recipes.md 行 126）

- 引句：「RMS 的目标值 0.2 来自附录 A 的五点扫描（ $\lbrace 0.05, 0.1, 0.2, 0.4, 0.8 \rbrace$ 中 0.2 与 0.4**明显**优于其余且彼此接近）」

- 建议：删「明显」（「五点扫描中 0.2 与 0.4 优于其余且彼此接近」的事实陈述已足），或补附录 A 的 loss 差值口径。

### S2-2 · 9.1 §3（01-sft.md 行 62）

- 引句：「多样性轴上 prompt 异质的 Stack Exchange **显著**优于 prompt 同质的 wikiHow。」

- 建议：补 LIMA §5 多样性对照的偏好率/分差口径，或删「显著」。

### S2-3 · 9.2 §3.1（02-rlhf-pipeline.md 行 46）

### S2-4 · 9.3 §7（03-dpo-family.md 行 189）

### S2-5 · 9.5 §6（05-rlvr-and-reasoning.md 行 153）
