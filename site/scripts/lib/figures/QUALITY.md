# 图品质量规（获奖级目标的评审打分维度）

目标品质：Awwwards / Webby Awards / FWA 获奖级。每张图五维打分（1-5 分制，全部 ≥4 才过线），评审必须附 Playwright 渲染实拍截图证据——源码目测不算评审。

## 五维

1. **动效自然度**：easing 有物理感（无匀速硬切、无机械匀速脉冲）；入场/循环节奏有呼吸感；reduced-motion 有静态终态。
2. **场景可读性**：不读正文也能一眼看懂数据流方向与层次；标签在正确的一侧；无交叉线打架。
3. **视觉层级**：主次分明（主链路最重）、留白充足、字级阶梯（标题/标签/注记三层）。
4. **细节完成度**：对齐、字距、端点圆角、深色图版下对比度、文本不溢框。
5. **与正文咬合**：图答正文之问（图的存在让读者少读一段话）；fig-tag 标题点题。

## 纪律

- 每维给分 + 一句证据（截图位置/元素名）；无 log 的「看着不错」视为未评审。
- 不达标（任一维 <4）打回重画，循环到过线。
- 组件库（figure-kit.mjs）API 签名不改；脉冲渐变用页面级 PULSE_GRAD_DEFS 的固定 id（勿引入 per-scene id 错配）；reduced-motion 必须有静态终态。
- 自检：`node scripts/fig-check.mjs <模块名>` 先行，截图复审随后。
